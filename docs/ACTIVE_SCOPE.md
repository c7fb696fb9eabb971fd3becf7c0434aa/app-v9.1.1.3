# Active Scope and Backlog Authority

The checked-in repository does not maintain a separate prioritized TODO list or roadmap. The
configured [GitHub Issues tracker](https://github.com/c7fb696fb9eabb971fd3becf7c0434aa/app-v9.1.1.3/issues)
is the work-item source unless the project owner adopts another source.

On 2026-10-12, the available GitHub issue query returned zero open issues. This is a dated
observation, not a durable empty-backlog guarantee. Recheck the tracker when starting work.

## Agent rules

- Follow an issue's acceptance criteria or the user's explicit task scope.
- Do not turn observations, missing features, or ideas into committed priorities without owner
  approval.
- If no tracker item or acceptance criteria exists and priority materially affects the work, ask
  the owner to establish it.
- Keep product capability status in the [Product Brief](./PRODUCT_BRIEF.md); keep rationale in an
  [ADR](./README.md#decisions-and-history). Do not duplicate those records here.
